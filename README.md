## Descripción

Este es un sistema desarrollado en Python utilizando Programación Orientada a Objetos (POO) para la gestión de una biblioteca digital.

La aplicación permite administrar libros, usuarios y préstamos, facilitando el registro, modificación, consulta y control de la información almacenada. Además, permite registrar devoluciones y consultar los préstamos activos del sistema.

## Funcionalidades

### Gestión de Libros

* Alta de libros.
* Modificación de libros.
* Baja de libros.
* Listado de libros.

### Gestión de Usuarios

* Alta de usuarios.
* Modificación de usuarios.
* Baja de usuarios.
* Listado de usuarios.

### Gestión de Préstamos

* Registro de préstamos.
* Registro de devoluciones.
* Consulta de préstamos activos.
* Validación de disponibilidad de libros antes de realizar un préstamo.

## Características Técnicas

El proyecto utiliza conceptos de Programación Orientada a Objetos, entre los que se incluyen:

* Herencia.
* Polimorfismo.
* Agregación.
* Composición.
* Decoradores personalizados.
* Metaclases.
* Patrón de diseño Singleton.
